# Source note: Insper Systems Thinking Program
URL: https://ee.insper.edu.br/cursos/gestao-e-politicas-publicas/pensamento-sistemico-para-analise-de-problemas-complexos/
Source classification: official program description, read 2026-11-19. This is a paraphrase, not a complete course syllabus.

Insper presents three thematic modules: (A) complex systems fundamentals, defining systemic problems, and the iceberg model; (B) mapping structure using causal loop diagrams, systems archetypes, and leverage points; (C) intervention strategy, leverage points, and an action roadmap. Program objectives include recognizing complex-system elements, mapping cause-and-effect relations, identifying leverage points, and proposing hypotheses about behavior over time.

Operational extension proposed for LOOP (NOT specified by Insper): evidence provenance, data access approval, review gates, structured data contracts, independent causal-claim checks, specialist handoffs, simulation validation, and human authorization for real-world interventions.
