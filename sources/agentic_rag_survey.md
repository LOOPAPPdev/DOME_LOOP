# Source note: Agentic Retrieval-Augmented Generation survey
URL: https://arxiv.org/abs/2501.09136
Title: Agentic Retrieval-Augmented Generation: A Survey on Agentic RAG; authors Aditi Singh et al. Latest observed revision v4 dated 2026-04-01.

The survey distinguishes conventional retrieval pipelines from agentic retrieval with planning, tool use, reflection, iterative search, and multi-agent collaboration. It organizes architectures by agent cardinality, control structure, autonomy, and knowledge representation. Documented challenges include evaluation, coordination, memory management, efficiency, and governance.

LOOP engineering choice, not a claim in the survey: bounded agent autonomy, separated query orchestration from source ingestion, deterministic evidence grading, specialist handoffs, and no automatic elevation of an unverified claim to fact.
